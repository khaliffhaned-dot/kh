# **App Name**: WARAC Hub

## Core Features:

- Membership Management: Allow users to select and pay for membership plans. Integrates with a payment gateway.
- Contact Form: Enable users to send inquiries via a contact form, integrated with email notifications to the admin.
- Gallery: Display images and videos of the archery club and its activities.
- Adaptive Training Schedules: Generates customized training schedules using AI to provide personalized workout plans, leveraging user performance data and goals.

## Style Guidelines:

- Primary color: Saturated gold (#FFD700), evoking the prestige and tradition of archery. 
- Background color: Dark navy (#191970) creating a sophisticated, calm, and focused atmosphere. 
- Accent color: Royal blue (#4169E1), complementing the primary with a harmonious, striking balance, perfect for interactive elements.
- Headline font: 'Playfair', a modern sans-serif similar to Didot with high contrast thin-thick lines for an elegant, high-end feel. Body font: 'PT Sans', a humanist sans-serif that combines a modern look and a little warmth.
- Use clean, modern icons from Lucide to represent various features and sections of the application. Icons should be in yellow.
- Employ a grid-based layout to ensure a structured and responsive design across different devices.
- Incorporate subtle transition animations to improve user experience when navigating between sections or loading content.
