# NADI ROI Framework

**NADI ROI is not media value. It is cost avoided + contribution proven + hours returned — under AMEC rules you already locked.**

If you sell AVE as NADI's ROI, you kill the product thesis. Measure what a CCO can defend upstairs.

---

## 1. Client ROI (what buyers should track)

Use three layers. Only the third is "money," and it stays conservative.

### A. Contribution (primary — already in product)

From Evaluation / `snap_`:

| Signal | How measured |
|--------|----------------|
| Objectives hit | O1–O5 green vs baseline (sentiment, pull-through, East MY share, 3R clear-in-48h, dual-calendar) |
| Contribution score | Weighted IEF ladder (15/25/35/25) |
| Week-on-week delta | Snapshot compare |
| Board pack used | Locked PDF actually went into a meeting |

**ROI language:** *"We moved O3 and O4; contribution 61 → 74; three moves executed."*
Not: *"RM X of media value."*

### B. Risk cost avoided (the real wow)

Assign only when the desk agrees the catch was real:

| Event | Proxy value (client sets the number) |
|-------|--------------------------------------|
| Residue cleared before national query | Cost of one crisis cycle (agency surge + leadership time) |
| East MY gap fixed before Malaysia Day story | Cost of reactive regional press recovery |
| 3R holding sent once, cleanly | Cost of a second apology / extended war room |
| Journalist query closed on SLA | Opportunity cost of a bad exclusive |

Formula clients can accept:

```
Risk avoided ≈ N_caught × C_typical_incident
```

`C` is **their** figure (e.g. RM 30–150k for a messy week), not a NADI rate card. Document assumptions in the snapshot limitations.

### C. Efficiency (hours and line items)

| Before NADI | After |
|-------------|--------|
| Junior clipping + Excel | Weekly pack auto |
| AVE report nobody trusts | Contribution pack |
| War room in WhatsApp | War room + decision log |
| Agency "monitoring" line | Partial replace or re-scope |

```
Efficiency ROI = (H_saved × loaded cost + displaced monitoring fees) / (NADI subscription + pilot)
```

Only count hours the client stops paying for — not theoretical "insight value."

### Optional: cost-per-outcome

Already in schema: client-entered campaign cost ÷ green objectives.
Legitimate efficiency metric. Still not AVE.

---

## 2. Simple pilot scorecard (8–12 weeks)

Agree this on day one:

| Metric | Target example |
|--------|-----------------|
| Weekly Evaluation opened by lead | ≥ 80% of weeks |
| Locked board PDF used once | ≥ 1 |
| Residue / East MY / 3R catches client confirms | ≥ 1 material |
| Objectives moved (any O) | ≥ 2 |
| Hours/week monitoring labour | −30% or more |
| AVE requests fulfilled by NADI | **0** |

Pilot ROI narrative:

> Subscription RM X. We avoided one residue escalation (est. RM Y on your scale), cut Z hours/week, and produced N contribution packs leadership actually used.

---

## 3. What not to use

| Metric | Why not |
|--------|---------|
| AVE / EMV / "PR value RM" | Barcelona 4.0; contradicts NADI |
| Impressions as ROI | Output, not outcome |
| "AI accuracy %" alone | Not a business result |
| Sentiment up = RM sales | Only if client has a closed attribution model |

---

## 4. Your ROI as seller (NADI the company)

Separate from client ROI:

| Metric | Meaning |
|--------|---------|
| Paid pilots → conversion | Product-market fit |
| Renewal / expansion Desk → Group | Sticky job-to-be-done |
| Time-to-first-wow in demo | Sales efficiency |
| Support hours per seat | Margin |
| CAC vs first-year ACV | Whether the wedge works |

Early: **one paid pilot that renews** beats ten free demos.

---

## 5. One sentence for the board pack

> NADI's return is measured as objectives met and incidents avoided under AMEC evaluation — not as advertising-equivalent ringgit.

That is consistent with Evaluation, war room, holdings, and trust centre. Teach buyers that sentence; then the scorecard above is just evidence.
