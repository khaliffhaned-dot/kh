# Crisis Communications Toolkit for Malaysian PLCs

This repository is intentionally scoped to crisis communications content only.

The active toolkit includes:
- `docs/crisis-communications-playbook-malaysia-plc.md` — core decision framework and crisis response playbook
- `docs/crisis-simulator/` — interactive browser-based crisis drills and facilitated exercises
- `docs/pdf-manual/` — PDF/manual generation kit for the playbook and pocket cards
- `docs/blueprint.md` and `docs/nadi-roi-framework.md` — supporting strategy and ROI framing

## Purpose

This repo is designed to help teams prepare, rehearse, and communicate clearly during material corporate crises in Malaysia, with emphasis on regulatory timelines, stakeholder management, and decision-quality under pressure.

## Start here

1. Review the playbook: `docs/crisis-communications-playbook-malaysia-plc.md`
2. Run the crisis simulator: open `docs/crisis-simulator/index.html` in a browser
3. Rebuild the manual: follow the instructions in `docs/pdf-manual/README.md`

## Repository focus

The repository has been narrowed to the crisis communications toolkit and excludes unrelated app/site code. The current active work is in the documentation, simulator, and manual-generation assets under `docs/`.
